# FaithConnect 💚

## Descripción

FaithConnect es una red social cristiana creada para compartir nuestra fe, conectar con otras personas y fortalecer nuestra relación con Dios.

Este proyecto fue desarrollado para las subáreas de Programación Web y Diseño de Software.

## Características principales

- Crear publicaciones con mensajes de fe.
- Dar y quitar «Me gusta» a las publicaciones.
- Filtrar publicaciones por categorías.
- Buscar publicaciones por su contenido.
- Eliminar publicaciones.
- Contador de publicaciones.
- Consultar versículos bíblicos.
- Visualizar videos cristianos.
- Consultar el perfil del usuario.
- Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Control de versiones

Se utilizó Git para registrar los cambios mediante commits, trabajar con ramas e integrar modificaciones mediante merge.

GitHub se utilizó para almacenar y mantener actualizado el repositorio del proyecto.
